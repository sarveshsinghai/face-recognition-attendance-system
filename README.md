# Face Recognition Attendance System

## 📌 Project Description
This project is a Face Recognition Attendance System developed using Python and OpenCV. It automatically detects and recognizes faces and marks attendance with the current date and time.

## 🚀 Features
- Face Detection using OpenCV
- Face Recognition
- Automatic Attendance Marking
- Date & Time Recording
- CSV Attendance Report

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Scikit-learn

## 📂 Project Files
- add_faces.py
- train_model.py
- attendance.py
- test_camera.py

## ▶️ How to Run
1. Add face data using add_faces.py
2. Train the model using train_model.py
3. Run attendance.py
4. Attendance will be saved automatically.
